A GTA 6 meme for make.fun's "Post a GTA 6 meme on X" bounty: the make.fun ghost rises as the sun over Vice City while a pink convertible cruises the boulevard — thirteen years of waiting, worth every sick day. The meme is posted on X from a public account; this repository hands in the post's address in POST.json, and main.ts copies it to /output for the gate to read. The picture itself is drawn by draw_meme.py with Pillow.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
